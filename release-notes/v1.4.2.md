**A small maintenance release.** Fixes furigana that appeared *after* a word instead of
above it on flashcard answers — most visible on the **Kaishi 1.5k** deck, where the
highlighted target word was affected.

> Immersion Suite is in **open beta**: stable enough for daily use and actively
> developed. Expect the occasional rough edge, and please
> [report bugs or request features](https://github.com/Mezuna-dev/Immersion-Suite/issues).

## What's new

### Fixed

- **Furigana now renders above the kanji on card answers, not after it.** On cards whose
  furigana wraps the highlighted word in bold — including the **Kaishi 1.5k** deck — the
  reading for that word was dropping inline after the kanji instead of sitting above it.
  Readings now position correctly above every word, and the small gaps that sometimes
  appeared between space-separated words are gone too.

## Download

| Platform | Installer |
|----------|-----------|
| **Windows 10 / 11 (64-bit)** | `ImmersionSuite_v1.4.2_Setup.exe` |
| **Linux (x86_64)** | `ImmersionSuite_v1.4.2_Linux_x86_64.run` |

On Linux, install with:

```bash
bash ImmersionSuite_v1.4.2_Linux_x86_64.run
```

Existing users can also update from inside the app: open it, and when the update prompt
appears, choose **Update Now**.

## Upgrading

- Your decks, cards, review history, and settings are preserved across the update —
  user data lives in the data folder and is not touched by the installer.
- No migration or reconfiguration is needed; this release only changes app behaviour, not
  your data.

## Known limitations (open beta)

- The browser extension is still loaded **unpacked** (a Web Store / Add-ons listing is
  planned). In Firefox, temporary add-ons are cleared on restart.
- The desktop app must be running for the extension to work.
- On Linux, the in-app updater launches the `.run` installer via `bash`; if your setup
  blocks that, download and run it manually instead.
